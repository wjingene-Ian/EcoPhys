# Project 3：沪深 288 只股票与九组全球市场

沪深部分使用 `data300_price` 中全部 288 个可用价格文件；全球部分对 `global_indices_price` 下九个子目录逐组使用全部可用文件，没有随机抽样。演示文稿前 17 页为沪深样本，后 27 页为九组全球市场，每组三页：特征值谱、样本外净值与回撤、压力期比较。

## 简易入口：一次分析一个指数文件夹

使用 `analyze_index.py`，在命令行提供输入文件夹路径即可运行。每个价格文件应有 `Date` 与 `ClosePrice` 两列。程序使用文件夹内全部可用股票以及共同交易日。

命令示例：

```bash
OPENBLAS_NUM_THREADS=1 /opt/anaconda3/envs/ml/bin/python analyze_index.py "/Users/wangxujing/Documents/courses/经济物理学/task/global_indices_price/cac40"
```

省略输出路径时，结果保存在本目录的 `runs/<输入文件夹名>/`；如需指定位置，在命令后加 `--output "/目标文件夹"`。每次生成三张 PNG 图（特征值谱、样本外净值与回撤、压力期比较），以及纳入清单、特征值、组合日收益、调仓记录、压力指标和摘要表。沪深 300 数据也可直接选择 `data300_price` 文件夹运行这一通用分析。

## 数据与方法

- 每组以所有文件共有的日期为日历；检查日期唯一、价格有限且为正。输入文件哈希和纳入清单见 `analysis/included_all.csv` 与 `global/<组名>/included_all.csv`。
- 全样本日对数收益逐股标准化后，计算相关矩阵、完整特征值谱和 MP 理论上下界。沪深样本另画经验矩阵、MP 主体、第一特征向量及其时间得分。
- 沪深第一特征向量的载荷平方按行业汇总，行业标签来自现有 `experiment/inputs/industry_map.csv`。
- 组合使用简单日收益。每次只用此前 504 个交易日估计协方差；RMT 去噪保留大于当期 MP 上界的特征值，将其余特征值替换为主体均值，重建相关矩阵并乘回训练期波动率。
- 原始与去噪协方差分别求长仓、满仓、单股初始权重不超过 5% 的最小方差组合。每 21 个交易日再平衡，期间权重随价格漂移；按换手额扣 10 bps。权重由带盒约束的投影加速梯度法求解。
- 压力日期由测试期等权股票篮子事后定义：20 日年化波动率最高 10% 为高波动；过去 21 日累计收益最低 10% 为市场下跌。两策略在完全相同的日期评价。压力期回撤是每段连续压力日期内的最大回撤，再取最差一段。

## 沪深样本结果

288 只股票在 2018-12-28 至 2026-09-28 有 1877 个共同价格日、1876 个日收益。MP 理论区间为 0.370–1.937；最大特征值为 79.56，解释 27.63% 的标准化方差，17 个特征值高于 MP 上界。第一特征向量载荷全部同号，有效参与数 245.3。行业标签覆盖全部股票的 26 个行业；金融股占数量 18.4%，载荷平方贡献 27.0%。

测试期为 2021-01-29 至 2026-09-28，共 1372 日。原始 / 去噪组合的年化 Sharpe 为 0.669 / 0.734，全期最大回撤为 −13.53% / −12.95%。高波动日的条件 Sharpe 为 2.652 / 2.645，连续压力段最深回撤为 −7.81% / −6.94%；市场下跌日的条件 Sharpe 为 −3.351 / −3.101，连续压力段最深回撤为 −6.82% / −6.90%。压力指标没有一致改善。

## 交付文件

- `output/Project3_沪深300与全球市场_RMT全样本_最终版.pptx`：44 页演示文稿。
- `analyze_index.py`：选择单个指数价格文件夹即可运行通用分析，提供命令行入口。
- `build_analysis.py`：沪深全部股票基础谱分析；输出 `analysis/`。
- `build_extension.py`：沪深行业映射、滚动组合、压力指标；输出 `extension/`。
- `build_global.py`：九组全球市场谱分析与组合评价；输出 `global/<组名>/`。
- 图全部为 PNG；逐日收益、调仓明细、压力日期及指标另有 CSV。

如需重建整套原始演示分析，运行顺序为 `build_analysis.py`、`build_extension.py`、`build_global.py`；这三个旧脚本使用本机固定数据路径。单个指数文件夹的分析直接运行 `analyze_index.py`，无需修改代码中的路径。

## 解释边界

输入是已有价格快照，未重新请求 API；价格复权口径、历史成分规则及抓取日志未独立核实。不同市场的股票池是所给文件的静态集合，可能有幸存者偏差。这里的“ETF”是成分股最小方差篮子代理，并非真实 ETF 的净值；未计入汇率、税费或实际流动性。不同市场表现不能直接视为同一货币或同一投资者的可比收益。压力阈值由测试期事后确定，不是实时择时信号。MP 区间是独立同方差随机收益的理论参照，不是逐个特征值的显著性检验。行业标签为当前快照，不代表完整历史分类。
