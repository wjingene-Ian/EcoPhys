# 沪深固定股票池长历史100股

从现有288股固定研究股票池检查最长可用日频复权记录，先按东方财富上市日期截断供应商的上市前记录，排除连续500日及以上价格不变的历史，再按最早起始日期选择100股。不是当前沪深300成分的历史重建，也不是动态成分股指数。

- 单股最早日期：1991-01-29。
- 第100只股票的起始日期：2002-02-05。
- 真正共有价格日期：2002-02-05 至 2026-11-09，6083日，约24.8年。
- 收益观测：6082日。
- 截止日期：2026-11-09，排除未完成的当日日线。

`prices/`为Date、ClosePrice两列pickle，可直接交给run.py；每只股票保留自身完整可用历史。
`daily_details/`保存复权收盘、供应商OHLC及成交量；`provenance/raw_yahoo/`保存100份原始接口响应。
`provenance/listing_dates/`保存100份上市日期核对响应。上市前记录共移除84条。
`candidate_histories.csv`记录全部候选及失败；`selected_stocks.csv`记录选择顺序和来源URL、哈希。
`common_adjusted_close.csv.gz`是100股共同日期的价格矩阵；没有补齐、前向填充或合成价格。

股票按历史可得性和事后数据质量选择，有上市历史/幸存者偏差，不能宣称代表1990年代以来每个时点的沪深300。供应商的最早可用记录不直接等同交易所上市日期；供应商复权历史可能随后续分红而更新。原始OHLC与AdjClose不是同一种调整口径，分析入口只使用AdjClose。停牌期间供应商可能提供连续不变价格；本程序没有自行填充，也未将它们当成新的成交记录。

运行：`python run.py hs300_long100`。
复抓：`python download_long_history.py --end 2026-11-09 --dataset-id 另一个新名字`。

## 对起始日期和停牌筛选的补充

未排除超长停牌时，100只最早历史的共同起点可到2002-01-11；其中000776.SZ有814个连续零收益日，会让部分500/504日窗口的方差为零。当前可直接运行pipeline的版本排除了这一候选，替补后共同起点为2002-02-05。未经该筛选的名单另存于`provenance/longest_start_selection_without_flat_run_exclusion.csv`，没有把其冻结价格作为正常可交易序列用于本次基础回测。

检查了全部候选的上市日期，12只候选存在供应商给出的上市前记录，共16918条；全部先截断再排序选择。最终100只的原始响应、上市日期证据和与原始样本的收益对照均保留。数据质量条件属于事后筛选，组合成绩不代表不存在选择偏差。
